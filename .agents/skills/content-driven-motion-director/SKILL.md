# SKILL: Content-Driven Dynamic Motion Graphics Director

## PRIMARY OBJECTIVE

Create visually original, professional, modern motion graphics for every input topic.

Every video must develop its own visual identity, animation language, storytelling structure and choreography based on its content.

The objective is NOT to produce videos using predefined animation templates.

## 1. CONTENT-DRIVEN CREATIVITY

Before creating visuals:

- Understand the subject deeply.
- Identify the most important message.
- Understand the target audience.
- Identify the emotional and educational purpose.
- Determine what visual representation best communicates the subject.

Never assume that two different topics should use the same animation approach.

## 2. NO FIXED SCENE TEMPLATES

Prohibited behavior:

- Reusing identical scene sequences.
- Always starting with kinetic typography.
- Always inserting a terminal scene.
- Always using statistics cards.
- Always ending with an identical CTA animation.
- Reusing the same visual metaphor for unrelated topics.

Choose scene structures dynamically.

Scenes may be short, long, continuous, fragmented or transformational according to the storytelling requirements.

## 3. VISUAL CONCEPT INVENTION

For each video, independently invent:

- Visual metaphors.
- Objects and characters.
- Graphic elements.
- Composition.
- Depth and perspective.
- Typography.
- Color palette.
- Camera movement.
- Scene transitions.
- Motion choreography.

Prefer meaningful visual demonstrations over decorative shapes and generic slides.

## 4. MOTION CHOREOGRAPHY

Every scene must have an intentional motion design.

Consider:

- Anticipation.
- Acceleration and deceleration.
- Spring movement.
- Controlled overshoot.
- Elastic settling.
- Object transformation.
- Parallax and depth.
- Camera tracking.
- Camera zoom and rotation.
- Continuous transitions.
- Audio-reactive movement.

Do not mechanically apply every technique to every scene.

Choose techniques according to the subject and intended visual effect.

## 5. CONTINUITY

Avoid PowerPoint-style scene changes.

Where appropriate:

- Objects should travel between scenes.
- Camera movement should connect compositions.
- Visual elements can transform into new elements.
- Transitions should emerge from the story.
- Motion should feel continuous rather than a collection of disconnected animations.

Do not introduce motion without a narrative or visual purpose.

## 6. NARRATION SYNCHRONIZATION

Use actual narration audio and Whisper word-level timestamps.

Synchronize:

- Object entrances.
- Important visual transformations.
- Typography emphasis.
- Camera movements.
- Sound effects.
- Captions.

Captions must reproduce spoken narration accurately.

## 7. ORIGINAL REMOTION IMPLEMENTATION

Generate original React TSX for the specific video.

Do not simply select a predefined scene template and replace its text.

Use appropriate techniques:

- Remotion animations.
- SVG.
- CSS.
- Canvas.
- Three.js where justified.
- Custom React components.
- Image and video assets.

Select the implementation based on visual requirements and available rendering resources.

## 8. CREATIVE SELF-REVIEW

Before completing the implementation, ask:

1. Does this video look specific to its subject?
2. Could this same animation be reused for an unrelated topic without modification?
3. Are the visual metaphors meaningful?
4. Is the motion choreography original?
5. Does the camera movement connect the story?
6. Are there unnecessary static periods?
7. Does the animation synchronize with narration?
8. Does it look like a modern motion graphics production rather than a slideshow?

If the answer to question 2 is yes, reconsider the creative direction.

## FINAL PRINCIPLE

Content determines storytelling.

Storytelling determines visual direction.

Visual direction determines choreography.

Choreography determines the Remotion implementation.

Never allow an existing animation template to determine the creative direction.
