Audio-First Timing

Rule 02
Zero Gaps / Overlaps

Rule 03

Rule 04
Two-Stage Render Gate
Preview render passes automated latency, motion, and sync checks before final render input freeze.

Technical Breakdown • Phases 1 to 4

Upstream Execution: Ingestion, Research & Audio Alignment

The Animation Bittrix pipeline operates through strict state machine transitions with explicit human-in-the-loop validation barriers. Below are the execution contracts for Phases 1 through 4.

Phase 01
Content Submission & Deep AI Research
POST /api/projects
Accepts raw input (topic, text, or url). The backend invokes the Codex CLI / Deep Researcher skill to ground all assertions in primary, verified academic and institutional sources. Shallow summaries are rejected.
Script Contract: Exactly 1 short, impactful sentence per scene. Scene 1 is always an attention hook.
Blueprint Scene JSON: Produces narration, visual blueprint tags, camera cues, and color palette.
Source Verification: Mandates open URLs, fact-checking notes, and token audit records.
Database State: Project stage transitions to script_review with script version 1.
Gate 01
Human Script Approval Barrier (Narration Freeze)
POST /api/projects/:id/scripts/approve
A reviewer audits narration phrasing, pacing, and visual intentions in the Web Dashboard. No audio generation or render job can proceed without this explicit cryptographic and database sign-off.
Narration Immutability: Once approved, the exact wording is frozen. Visual adjustments cannot alter spoken words.
Revision Loop: If changes are requested (/scripts/revise), a new monotonic version is spawned.
Phase 02
Speech Synthesis & Sub-Frame Alignment
Kokoro TTS + Whisper STT
Synthesizes high-fidelity speech for each scene narration sentence. Audio files are converted to broadcast MP3 via ffmpeg and measured with ffprobe to determine precise frame counts.
Dynamic Scene Timing: Scene start = word0 - (5 to 8 frames). Scene end = wordN + short hold.
Word-Level Captions: Sub-frame word timestamps drive active kinetic highlighting with 0.00s offset.
Zero Gaps/Overlaps: Audio files are concatenated into a master track. Scene durations tile the track perfectly.
No Time-Stretching: If voice exceeds target limits, Kokoro natural speed is incremented; no artificial warps.
Phase 03
Procedural SFX & Acoustic Bed Synthesis
scripts/make_sfx.py
Every on-screen object entrance, kinetic typography hit, and camera movement is scored with a procedural, license-free sound effect aligned to the exact transient hit frame.
Sound Roles: Synthesizes deterministic pop, click, whoosh, slide, riser, impact, sparkle, chime, and ding.
Transient Shift: Compensates for sound rise time so the auditory transient peaks on the visual frame.
Continuous Bed: Generates a procedural background bed with automatic speech ducking (-14dB).
Cue Manifest: Writes .cues.json containing frame-by-frame sound triggers and volume envelopes.

Technical Breakdown • Phases 5 to 8 & Gates

Downstream Execution: Motion, Quality Gates & Final Release

The rendering pipeline strictly bifurcates into Stage 1 (Fast Preview & Automated Verification) and Stage 2 (Locked Input Production Render).

Phase 04
Visual Scaffolding & Continuous Motion Rules
Remotion 4 + React Canvas
Constructs React composition props adhering to vertical 9:16 layout standards. Embeds kinetic typography, vector schematics, 3D models, and dynamic particle systems.
Continuous Motion Rule: Every scene must maintain continuous slow zoom, orbiting glow, and fluid drift. Motion Energy ≥ 0.80.
Zero Meta-Clutter: Forbids debug text, terminal windows, code chrome, or placeholder counters.
Mobile Safe Zone: Keeps text elements within strict vertical margins (top 15%, bottom 20% clear for social UI).
Mandatory Outro: Renders official Bittrix outro (bittrix-logo.mp4) during final 90 frames (3.0s).
Phase 05
Stage 1: Headless Preview Render & Quality Gates
remotion-host.mjs + qualityGate.mjs
Renders a versioned preview (<topic>_preview_vN.mp4) and executes an automated, 8-point pass/fail QA validation suite before the preview is eligible for human review.
Latency Validation: Scene lag must remain between -0.30s and +0.10s. Caption lag between -0.10s and +0.20s.
Acoustic Sync Check: verify_sync.py verifies SFX audio transients against visual hit frames using SciPy cross-correlation.
Canvas Overlap Gate: Checks text bounding boxes to ensure no overlapping typography or clipped safe-area zones.
Retry Guardrail: If any check fails, system auto-adjusts layout/timing and retries (maximum 3 attempts).
Gate 02
Human Preview Review & Approval Barrier
POST /api/projects/:id/previews/approve
The reviewer watches the completed preview video in the Frontend player. Approval must target the exact preview version ID and completed render job before final production is unlocked.
Version Pinning: Prevents race conditions by pinning the exact preview artifact that was inspected.
Visual Feedback Loop: If rejected, visual revisions spawn a new blueprint version without rewriting audio.
Phase 06
Stage 2: Input Freeze & Full 1080×1920 Production Render
POST /api/projects/:id/final-render
Freezes all inputs with SHA-256 checksums. Executes the full-resolution final render. Validates strict preview-to-final parity before delivering to the Video Library.
Input Freeze: Locks audio clips, cue manifests, and JSON props. No assets are refetched or recomputed.
Parity Verification: Confirms final render scene starts and caption starts match preview within 0.05 seconds.
Library Publishing: Saves final deliverable to /media/videos/:id_final.mp4 with full duration and metadata.
Audit Persistence: Stores permanent run records in database tables videos and agent_runs.
