    1. Think in frames, not in CSS timing

    Every frame must be a pure function of the frame number. That is how Remotion works, and it is why you can scrub the sample above. Nothing depends on what happened before, so previews and final renders always match.

    const FPS = 30, DURATION = 150;           // 5 seconds
const clamp = (v) => Math.min(1, Math.max(0, v));
const progress = (f, start, len) => clamp((f - start) / len);
const easeOut = (t) => 1 - Math.pow(1 - t, 3);

// every element: opacity + 20-30px slide, driven only by f
const p = easeOut(progress(f, 24 + i * 8, 16));
el.style.opacity = p;
el.style.transform = `translateY(${(1 - p) * 24}px)`;

    2. Layout rules

    • Lock one canvas1080×1920 for vertical, 1920×1080 for horizontal. Put the numbers in one constants file and import it everywhere.
    • Split the canvas into zones that never share pixelsSafe margin 80px, then title, bullets, media, captions. Toggle “Show zones” on the sample to see them.
    • Use flex or grid inside each zoneWrapped text then pushes siblings down. Absolute positioning is what caused the overlaps in your screencast.
    • Limit the contentTitle: 2 lines. Bullets: 3 maximum, 1–2 lines each. Caption: 2 lines.
    • NeverPlace text over a screenshot, let captions enter the media zone, or clip a title at the canvas edge.

    3. Treat screenshots like footage

    • Crop to one ideaHero, one card, one feature. A full-page capture shrunk to 300px is unreadable.
    • Fill the media zone widthMinimum 85% of the zone width, inside a browser or device frame with rounded corners and a deep soft shadow.
    • Move slowlyScale from 1.0 to 1.08 over the whole scene, or pan about 6%. Slow beats fancy.

    4. Animation rules

    ThingValue
    Entrance12–20 frames, ease-out or spring
    Exit6–10 frames, shorter than entrance
    Stagger between bullets6–8 frames
    Slide distance20–30px plus fade
    Scene transition10–12 frame crossfade or slide, never a hard cut
    Things moving at once3 or fewer
    Linear easingOnly for continuous drift like the screenshot push

    5. Type and color

    • One family, two weights, three sizesTitle 96px, body 52px, caption 50px at 1080 wide. Never below 44px on a vertical video.
    • One accent colorDark background, white text, one accent for emphasis and the active caption word.
    • Highlight with color, not sizeChanging size reflows the caption line and makes it jump.
    • Auto-fit instead of hopingIf the title overflows, shrink the font in 4px steps down to a minimum. Try the “Break it” button with Auto-fit on and off.
    function fitText(el, max = 96, min = 56) {
  let s = max;
  el.style.fontSize = s + 'px';
  while (el.scrollHeight > el.clientHeight && s > min) {
    s -= 4; el.style.fontSize = s + 'px';
  }
}

    6. Narration and timing

    • Voice sets the durationScene length = voiceover length + about 0.4s. Never hardcode seconds.
    • Use word timestampsReveal each bullet when the narrator starts that sentence. Highlight the caption word being spoken.
    • Order of workScript → voiceover → timestamps → layout → animation → sound. Audio timing is last because it depends on final durations.

    8. The quality gate

    This is the part that makes the pipeline reliable. Before “Approve Preview”, render the start, middle, and end frame of every scene and run automatic checks. The panel under the sample runs the same logic live. Fail means regenerate, not ship.

    for (const scene of scenes) {
  for (const f of [0, mid, end - 1]) {
    renderFrame(scene, f);
    const issues = [
      ...zoneOverflow(scene),      // content taller than its zone
      ...zoneOverlap(scene),       // two zones touching
      ...outOfCanvas(scene),       // text past the edge
      ...tooSmall(scene, 'media')  // screenshot under 85% width
    ];
    if (issues.length) return regenerate(scene, issues);
  }
}
